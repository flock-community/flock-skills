# Steps 4-7: Project Generation & Structure

## Step 4: Fetch Current Spring Boot Version

Query Spring Initializr metadata to get the current default version:

```bash
# Get JSON metadata with available versions
curl -s -H "Accept: application/json" https://start.spring.io | jq -r '.bootVersion.default' | sed 's/.RELEASE$//'
```

The response contains:
- `bootVersion.default` - recommended Spring Boot version (use this)
- `bootVersion.values` - all available versions
- `javaVersion.default` - default Java version

Store the result as `BOOT_VERSION` for use in project generation and build files.

## Step 5: Generate Base Project

Use Spring Initializr via curl to generate the base project, using the dynamically fetched `BOOT_VERSION`.

**Important**: Use `-d` flags (not `--data-urlencode`) for reliable parameter passing:

```bash
curl -G "https://start.spring.io/starter.tgz" \
  -d "type=gradle-project-kotlin" \
  -d "language=kotlin" \
  -d "bootVersion=${BOOT_VERSION}" \
  -d "baseDir={project-name}" \
  -d "groupId={group-id}" \
  -d "artifactId={project-name}" \
  -d "packageName={group-id}" \
  -d "javaVersion=21" \
  -d "dependencies=web" \
  | tar -xzf - -C {target-directory}
```

For Maven, use `type=maven-project` instead.

## Step 6: Transform to Multi-Module Structure

Create the following directory structure:

```
{project-name}/
├── domain/
│   └── src/
│       ├── main/kotlin/{package-path}/domain/
│       └── test/kotlin/{package-path}/domain/
├── api/
│   └── src/
│       ├── main/kotlin/{package-path}/api/
│       └── test/kotlin/{package-path}/api/
├── adapters/                    # Parent directory only
├── app/
│   └── src/
│       ├── main/kotlin/{package-path}/
│       ├── main/resources/
│       └── test/kotlin/{package-path}/
├── build.gradle.kts             # Root build file
└── settings.gradle.kts
```

Move the generated Application class to `app/src/main/kotlin/...`

**Cleanup**: Remove the `HELP.md` file generated by Spring Initializr (not needed).

## Step 7: Configure Build Files

### Root build.gradle.kts

Use `${BOOT_VERSION}` from Step 4 for the Spring Boot version:

```kotlin
plugins {
    kotlin("jvm") version "2.2.20" apply false
    kotlin("plugin.spring") version "2.2.20" apply false
    id("org.springframework.boot") version "${BOOT_VERSION}" apply false
    kotlin("plugin.serialization") version "2.2.20" apply false
    id("io.spring.dependency-management") version "1.1.7" apply false
    id("dev.detekt") version "2.0.0-alpha.1" apply false
}

allprojects {
    group = "{GROUP_ID}"
    version = "0.0.1-SNAPSHOT"

    repositories {
        mavenCentral()
    }
}

subprojects {
    apply(plugin = "io.spring.dependency-management")

    the<io.spring.gradle.dependencymanagement.dsl.DependencyManagementExtension>().apply {
        imports {
            mavenBom("org.springframework.boot:spring-boot-dependencies:${BOOT_VERSION}")
            mavenBom("io.arrow-kt:arrow-stack:2.2.0")
        }
    }

    tasks.withType<org.jetbrains.kotlin.gradle.tasks.KotlinCompile> {
        compilerOptions {
            freeCompilerArgs.addAll("-Xjsr305=strict", "-Xannotation-default-target=param-property", "-Xcontext-parameters")
        }
    }

    plugins.withId("org.jetbrains.kotlin.jvm") {
        extensions.configure<JavaPluginExtension> {
            toolchain {
                languageVersion.set(JavaLanguageVersion.of(21))
            }
        }
    }
}
```

### settings.gradle.kts

```kotlin
rootProject.name = "{project-name}"

include("domain")
include("api")

// Adapter modules added as: include("adapters:{adapter-name}")
```

### domain/build.gradle.kts

```kotlin
plugins {
    kotlin("jvm")
    id("dev.detekt")
}

// Force detekt to use the Kotlin version it was compiled with
configurations.matching { it.name == "detekt" }.all {
    resolutionStrategy.eachDependency {
        if (requested.group == "org.jetbrains.kotlin") {
            useVersion("2.2.20")
        }
    }
}

dependencies {
    implementation("io.arrow-kt:arrow-core")
    implementation("org.springframework:spring-context")

    testImplementation("org.jetbrains.kotlin:kotlin-test-junit5")
    testImplementation("org.jetbrains.kotlinx:kotlinx-coroutines-test")
    testRuntimeOnly("org.junit.platform:junit-platform-launcher")

    detektPlugins("community.flock:hexagonal-detekt-rules:1.0.0")
}

detekt {
    buildUponDefaultConfig = true
    config.setFrom(files("$projectDir/detekt.yml"))
}

tasks.withType<Test> {
    useJUnitPlatform()
}
```
